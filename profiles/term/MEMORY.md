# Term memory

Store only durable, user-approved information that improves future work.

Good candidates:

- confirmed project names and repository locations
- stable technical preferences
- decisions about the agent's role and boundaries
- completed setup milestones
- recurring workflow preferences

Do not store:

- API keys, passwords, cookies, bearer tokens, refresh tokens, private keys
- financial account details
- sensitive personal information unless the user explicitly requests a safer, clearly scoped record
- unverified claims
- temporary one-time instructions

When uncertain, ask before recording.
